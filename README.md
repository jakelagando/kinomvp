# Kino MVP

Kino is a body-composition tracking app concept. Users upload front and side phone photos, receive body-fat and muscle-mass measurements, and compare results over time.

## Run locally

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000>.

## Current scope

- Phone photo upload flow
- Demo scan-analysis state
- Body-fat and muscle-mass result cards
- Latest-scan comparison
- Scan history and progress tracking
- Responsive mobile layout

The current analysis uses sample values. A production body-composition model or API still needs to be connected.
